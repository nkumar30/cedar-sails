# Cedar Sails ⛵🌲

A Phoenician ship race along the coast of Lebanon, for kids.

**Play:** https://nkumar30.github.io/cedar-sails/

- Open the link on a big screen (laptop or TV).
- Players join from their phones: scan the QR code, or open the link and tap the yellow **Enter Game Code** button. No sign-in needed.
- First to 12 deliveries wins. If everyone else sinks, the last ship standing wins!
